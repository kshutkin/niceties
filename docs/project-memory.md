# niceties — Project Memory

## Overview

Monorepo of small, focused Node.js/web packages under the `@niceties` npm scope.
GitHub: https://github.com/kshutkin/niceties

All packages are **ESM-first** (`"type": "module"`), **tree-shakeable**, ship **sources directly** (no `dist/` — `src/` and `types/` are in `files`), and require **Node ≥ 15** (except `node-parseargs-plus` which requires ≥ 18.3.0).

## Tooling

| Tool | Role |
|---|---|
| **pnpm** + `pnpm-workspace.yaml` | Monorepo package manager; `hoistWorkspacePackages: false` |
| **vitest** (v4) | Test runner; shared config at root `vitest.config.js` |
| **@vitest/coverage-v8** | Coverage; each package outputs to its own `coverage/` dir |
| **Biome** (v2) | Linter + formatter (replaces ESLint + Prettier) |
| **dts-buddy** | Generates `types/index.d.ts` from JSDoc; run via `pnpm build` in each package |
| **pkgprn-internal** | `prepack` step — flattens `types,src` and strips comments before publish |
| **@changesets/cli** | Versioning and changelog management; publish via `pnpm ci:publish` |
| **Renovate** | Automated dependency updates (`renovate.json` at root) |

## Root Scripts

```sh
pnpm build        # dts-buddy in all packages (generates types)
pnpm test         # vitest run --coverage in all packages (parallel, forks pool)
pnpm lint         # biome check .
pnpm lint:fix     # biome check --write .
pnpm ci:publish   # changeset publish
```

---

## Per-Package Scripts (standard)

```sh
pnpm build     # dts-buddy
pnpm prepack   # pkgprn-internal --flatten types,src --strip-comments
pnpm test      # vitest run --coverage --config ../vitest.config.js
```

Tests live in `<package>/tests/*.spec.mjs`; vitest `include` glob is `**/tests/**/*.spec.mjs`.

---

## Vitest Config (root)

- `environment: 'node'`, `pool: 'forks'`
- `execArgv: ['--expose-gc']` (allows GC benchmarks)
- Coverage excludes: `node_modules`, `tests/`, `dist/`, `types/`, `*.config.js`, `*.d.ts`
- Coverage `reportsDirectory: './coverage'` (relative to each package when run from package root)

---

## Biome Config Conventions

- `indentStyle: space`, `indentWidth: 4`, `lineWidth: 140`, `lineEnding: lf`
- Single quotes (`quoteStyle: single`)
- Trailing commas: `es5`
- Semicolons: always
- Arrow parens: `asNeeded`
- Import groups order: **Node built-ins → blank → third-party (excluding `@slimlib/**` and `@niceties/**`) → blank → `@slimlib/**` + `@niceties/**` → blank → relative paths**

---

## Package Structure Convention

```
<package>/
  src/           # source files (shipped)
  types/         # generated .d.ts (built by dts-buddy, shipped)
  tests/         # *.spec.mjs (not shipped)
  coverage/      # generated by vitest (gitignored)
  package.json
  tsconfig.json
  CHANGELOG.md
  README.md
```

Exports pattern — all subpath exports use `"types"` + `"default"` (no CJS):
```json
"exports": {
  ".": { "types": "./types/index.d.ts", "default": "./src/index.js" },
  "./package.json": "./package.json"
}
```

## CI / Release

- GitHub Actions: `.github/workflows/main.yml` delegates to reusable workflow `kshutkin/pipeline/.github/workflows/main.yml@main` with `scope: '@niceties'` and `secrets: inherit`.
- Triggers on push/PR to `main`, semver branches (`1.x`, `1.0.x`, …), and pre-release branches (`next`, `alpha`, `beta`, `next-major`).
- Releases managed by **Changesets**; run `pnpm changeset` to record a change, `pnpm ci:publish` to publish.

---

## Cross-Package Dependencies

- `@niceties/draftlog-appender` has `@niceties/logger` as both a `devDependency` (`workspace:*`) and `peerDependency` (`workspace:^`).
- `examples/` imports from workspace packages.

## Notes / Gotchas

- Sources are shipped as-is (no transpilation); consumers must support ESM.
- `dts-buddy` reads JSDoc to emit declarations — no separate `.ts` source files.
- `pkgprn-internal` runs on `prepack` (before `npm publish` / `pnpm publish`), not at build time — do not rely on the flattened output during development.
- Coverage `reportsDirectory` in vitest config is `'./coverage'` — when tests run from the monorepo root this lands in the root `coverage/`; individual packages run `vitest --config ../vitest.config.js` so coverage lands in `<package>/coverage/`.
- `.npmrc` is present at root (likely sets `shamefully-hoist` or registry config — check before adding new deps).
